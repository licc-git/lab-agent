# 实验室安全规范

## 一、进入与着装
1. 进入实验室须穿实验服，**化学实验室须戴护目镜**；长发须束起，不得穿拖鞋、凉鞋、高跟鞋，避免佩戴易悬挂的饰品。
2. 首次进入实验室前须完成**安全教育培训并通过考核**，签订安全责任书后方可获得使用资格。
3. 涉及腐蚀性、毒性试剂或加热、高速运转设备的实验，还应根据要求佩戴防护手套、面罩等相应防护用品。

## 二、行为规范
1. **禁止把零食带进化学实验室**；所有实验室内一律禁止饮食、存放食品，防止误食有毒物质或污染样品。
2. 实验室内严禁烟火，保持安静，不得追逐打闹、大声喧哗；严禁私拉乱接电线和使用违规大功率电器。
3. 严禁私自搬动、外借实验室设备和器材；与本人实验无关的仪器、试剂不得擅自动用。
4. 产生刺激性或有毒气体的实验，必须在通风橱内进行，并保证排风正常运行。
5. 浓酸、浓碱等腐蚀性试剂取用须格外小心，稀释时应将酸缓慢倒入水中，不得反向操作。

## 三、设备与故障处理
1. **设备损坏应立即停用，并联系实验室管理员，不要自行拆修**；严禁带电检修、湿手触碰电气设备。
2. 使用中发现异响、异味、冒烟、异常升温等异常情况，应立即断电停机并上报，不得带故障继续运行。
3. 精密仪器运行期间须专人值守，不得长时间离开现场。

## 四、应急处理
1. 试剂溅入眼睛或接触皮肤，立即用大量清水持续冲洗（或使用洗眼器、紧急喷淋装置）并及时就医。
2. 发生小型火情，先切断水电气源，使用对应类型灭火器扑救；电器、化学品火灾严禁用水直接扑救。
3. 发生化学品大量泄漏、气体泄漏等重大隐患，立即撤离现场并上报管理员，必要时拨打应急电话，不得盲目处置。
4. 请提前熟悉实验室内灭火器、灭火毯、急救箱、洗眼器及安全出口的位置和使用方法。

## 五、离场要求
1. **离开前关闭电源、水源，清理台面**，确认气路、门窗全部关闭；最后离开者须进行整体安全检查。
2. 实验废液、废渣须分类投入指定回收容器，严禁倒入下水道或随意丢弃；剩余试剂按规定回收，不得带出实验室。
3. 经管理员检查确认现场合格后方可离开；未清理现场、未断电关水的，记入违规记录。
