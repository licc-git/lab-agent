# 实验室预约规则

## 一、预约提交
1. 用户须使用本人账号登录系统后，打开实验室列表页面，按"先选择实验室或设备 → 填写日期和时段 → 填写实验内容/使用目的 → 提交"的顺序完成预约申请。
2. 预约需**提前至少 1 个工作日**提交，当天临时申请原则上不予受理；大型精密仪器、夜间及节假日使用需提前 3 个工作日提交，并附实验安全预案。
3. 预约设备时必须同时选择其所属实验室；设备与实验室绑定，约了设备，对应时段内实验室也一并占用。
4. 同一用户同一时段只能提交一条有效预约；单次预约时长原则上不超过 4 小时，确需延长的应在备注栏说明原因。
5. 提交前请核对预约信息（实验室/设备、日期、时段、人数、实验内容），提交后不可自行修改，如需变更须先取消再重新提交。

## 二、审核规则
1. 预约提交后状态为**待审核**，须由实验室管理员审核通过后方可进入使用，未通过审核的预约不产生使用权限。
2. 管理员原则上在 **1 个工作日内**完成审核；请在预约时段开始前主动查看审核状态。
3. 审核未通过时，系统将显示拒绝原因（如：时段冲突、实验室维护、安全预案缺失、资格不符等），申请人可修改后重新提交。
4. 当多个申请时段冲突时，按提交时间先后确定优先级；教学任务、竞赛集训等优先于一般自主实验。
5. 审核通过后请按时到场使用；**超过预约开始时间 30 分钟未签到的，系统自动作废该条预约**，时段开放给他人临时申请。

## 三、取消与变更
1. **待审核、已通过的预约，本人可以取消；已拒绝的预约不能取消**（仅可查看拒绝原因）。
2. 已通过的预约如需取消，请**至少提前 2 小时**在系统中操作，以便释放时段供他人使用。
3. 预约生效后未按时使用且未提前取消的，记为**违约（爽约）一次**；累计 3 次违约将暂停预约权限 7 天，须完成安全再教育后方可恢复。
4. 因学校/实验室临时安排（教学调整、设备检修、安全排查）被统一取消的预约，不计入个人违约记录。
5. 预约人与实际使用人须一致，转借账号、私自授权他人使用均属违规，一经查实双方均暂停预约权限。

## 四、现场核验
1. 进入实验室时请出示预约凭证（或刷卡/扫码签到），管理员核验预约信息与本人身份一致后方可进入。
2. 使用结束后请在系统中**签退**并填写使用记录，作为实验室运行台账留存备查。
