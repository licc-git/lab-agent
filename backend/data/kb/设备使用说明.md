# 设备使用说明

## 一、预约与绑定
1. **预约设备时必须同时选择所属实验室**，仅选设备不选实验室的申请不予受理。
2. **设备与实验室绑定：约了设备，时段内实验室也占用**；请按实际需要合理预约，避免资源浪费。
3. 同一用户单次预约同一设备时长原则上不超过 3 天；多人集中测试需提前说明并经管理员协调。

## 二、使用资格
1. 使用贵重及精密设备前，须完成对应设备的**操作培训并通过考核**取得认证资格；未取得资格者不得独自操作，可由已认证人员现场陪同。
2. 设备优先级依次为：管理维护 > 已生效预约 > 临时申请；请按预约时段准时到场，逾时未签到视为放弃。

## 三、电子显微镜操作要点
1. **使用前先检查镜头和样品台**：确认镜头无污染、无划痕，样品台清洁、固定到位、运动正常；发现异常立即报告管理员，不得强行使用。
2. 装载样品前确认样品尺寸、干燥度、导电性符合要求，避免污染镜腔。
3. 使用过程中不得擅自离开设备，参数调整应循序渐进，避免瞬时大束流损伤样品或探测器。
4. **结束后填写使用登记**，内容包括：使用人、起止时间、样品信息、设备状态、异常情况记录等，作为设备运行档案留存。
5. 使用完毕后将各部件恢复初始状态，退出软件、按顺序关机，清理样品台及操作台面。

## 四、通用使用规范
1. 使用前请核对设备外观、配件完好性，有问题当场向管理员反馈，否则视为交接口状态良好，后续损坏由使用人承担。
2. 严禁擅自拆卸、改装设备或更改系统配置；未经许可不得将设备、配件带出实验室。
3. 使用中发生故障、卡死、读数异常等，立即停止操作并断电，联系管理员处理，**不得自行拆修**。
4. 因违规操作造成设备损坏的，须照价赔偿（情节严重的按 1–2 倍赔偿），并暂停设备预约权限；故意损坏的加倍追责。
5. 设备使用产生的重要数据请自行备份，实验室不承担共用电脑数据的保管责任。
